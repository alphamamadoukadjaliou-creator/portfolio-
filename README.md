# Portfolio — Alpha Mamadou Kadjaliou Diallo

Portfolio personnel d'un étudiant en Licence 2 Télécommunications & Informatique, passionné par le développement web, les réseaux et la cybersécurité.

**Site en ligne :** https://alphamamadoukadjaliou-creator.github.io/portfolio-/

## Fonctionnalités

- Design responsive (ordinateur, tablette, mobile) avec menu mobile
- Thème sombre / clair mémorisé dans le navigateur
- Animations au défilement et barres de compétences animées
- Formulaire de contact fonctionnel via [Formspree](https://formspree.io)
- Accessibilité : navigation au clavier, libellés, respect de « réduire les animations »
- Aucune dépendance : HTML, CSS et JavaScript natifs

## Structure

```
.
├── index.html              # Page unique du site
├── css/style.css           # Styles (variables de thème en haut du fichier)
├── js/main.js              # Menu, thème, animations, formulaire
└── assets/
    ├── img/                # Photo de profil, visuels de projets
    ├── docs/               # CV
    └── downloads/          # Fichiers de projets téléchargeables
```

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python -m http.server 8000
```

puis aller sur http://localhost:8000.

## Déploiement

Le site est statique : il fonctionne tel quel sur GitHub Pages, Netlify, Vercel ou n'importe quel hébergeur web (déposer le contenu du dossier à la racine du site).
